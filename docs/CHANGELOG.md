# Changelog

## [1.0.0] - 2026-09-04

Open Ends 的第一个正式版本。

### Added

- Today / Daily Focus
- Open Threads
- Spark capture、revision 与 AI organization
- Month view
- Reading / Media
- Review / Living Profile
- TodoPanel
- SparkCapture
- Local SQLite
- JSON backup / restore
- Theme / Edition foundation

### Desktop

- Windows x64
- Frameless MainWindow
- TodoPanel dock / auto-hide
- Tray 与全局快捷键
- NSIS / MSI 安装包

### Integrations

- DeepSeek
- TMDB
- Google Books

### Privacy

- Local-first data storage
- Windows Credential Manager for service credentials
- No account and no Open Ends cloud sync
