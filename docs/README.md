# Open Ends Documentation

以下是随公开仓库发布的稳定文档及其用途：

- [Product](PRODUCT.md)：说明产品定位、核心体验、功能边界和用户场景。
- [Architecture](ARCHITECTURE.md)：说明系统分层、模块职责、数据流以及各层之间的依赖边界。
- [Database](DATABASE.md)：说明 SQLite schema、migration、表关系、约束和备份数据规则。
- [API & Integrations](API.md)：说明前端与 Tauri 的调用边界、数据命令以及 DeepSeek、Google Books、TMDB 等外部服务接口。
- [Desktop](DESKTOP.md)：说明 Windows 桌面壳、主窗口与辅助窗口、托盘、快捷键、TodoPanel dock 和构建产物契约。
- [Style Guide](STYLE_GUIDE.md)：说明 Classic Edition 与 Graphite Amber Theme 的字体、颜色、层级和状态表现规范。
- [Theme API](THEME_API.md)：说明 Theme manifest、semantic tokens、图标、资源槽位及兼容性约束。
- [Edition API](EDITION_API.md)：说明 Edition 的导航、Shell、页面 renderer 和辅助窗口 renderer 扩展契约。
- [Roadmap](ROADMAP.md)：记录已发布版本和后续版本的功能方向与优先级。
- [Changelog](CHANGELOG.md)：按版本记录已经发布的功能、修复和重要变更。
